## 3. What to look for

1. **The emulator switch**, [main.dart:20-25](../../lib/main.dart:20). It always passes `localhost`. On Android, `firebase_core`'s `getMappedHost` rewrites that to `10.0.2.2`, so the spec's host rule holds without a platform check.
2. **Order of operations**, [main.dart:15-23](../../lib/main.dart:15). Web persistence is set before the emulator calls and before any Firestore use. Firestore ignores settings applied after first use.
3. **Old Gradle plugin**, [settings.gradle.kts:24](../../android/settings.gradle.kts:24). FlutterFire's 4.3.15 builds fine with AGP 9.1 (the latest is 4.6.0), so I kept it, as the plan said.
4. **Upstream warning** from the APK build: `firebase_core` applies the Kotlin Gradle Plugin, which "future versions of Flutter will fail to build". It's FlutterFire's to fix; watch it on Flutter upgrades.
